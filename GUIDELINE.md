## Standard Codes

- Country: ISO_3166-1, both alpha-2 code and numeric code can be used in different case
- Market: Market Identifier Code(MIC)(ISO_10383), e.g. xshg for SSE and xshe for SZSE, and ASCII for UPPER CASE will be used in a numeric case
- Assets：an in-housing shortcut subject to Classification of Financial Instruments(CFI)(ISO_10962), e.g ES for equity shares and ES.AM for equity A shares in main board in China Market
